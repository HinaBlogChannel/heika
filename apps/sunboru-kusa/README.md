# すんぼる草不可避

送金で生えます。

自分のアドレスから送り先のアドレスへ 1 XYM 以上を送るたびに、4×4 の畑に何かが1つ生えます。何が生えるかは送金のハッシュだけで決まり、たいていは草で、ときどき白樺、屋久杉、ヒノキ、ひまわり、ハエトリグサなどが生えます。珍しいものに優劣はありません。

- 鍵は使いません。REST から送金の履歴を読んで描くだけです。ウォレットをつなぐ必要もありません
- 数えるのは、自分のアカウントが署名した送金だけです（アグリゲートの中も含む）。ほかの人が代わりに育てることはできません
- 確定した高さまでの送金を数えます。まだ確定していない分は、薄く「育ちかけ」で描きます
- 数えたところまでをブラウザに覚えておきます。覚えていなければ、最初から順に生やして振り返ります
- 送り先は自由に変えられます。テストネットや、自分のプライベートネットでも遊べます。払う義務はありません
- 畑は PNG で保存、シェアできます。シェアする画像と文には、アドレスを入れません

## ビルド

```sh
trunk build --release
```

`dist` を静的なファイルとして、どこにでも置けます。URL に `?rest=…&to=…&me=…` を付けると、開いたときにその畑を見ます。
